# Accessibility

Project Wayfinder aims to make every core task conform to WCAG 2.2 AA and to go further for cognitive accessibility.

To report a barrier, open an accessibility issue using:

- the task you were trying to complete;
- device, operating system, browser or app version;
- assistive technology and version, if comfortable sharing;
- what happened and what you expected; and
- screenshots or recordings only if they contain no private information.

Do not include diagnoses or personal schedule, wardrobe, location, or supporter details in a public issue. Use the private security contact for any report involving personal-data exposure or an unsafe access-control behavior.

Maintainers will acknowledge an accessibility report within three working days, provide a triage status within seven, and prioritize blockers in core independence flows for the next patch release.

See [Accessibility Architecture](docs/design/ACCESSIBILITY.md).
