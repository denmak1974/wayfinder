# Contributing to Wayfinder

First of all, thank you for your interest in contributing to Wayfinder.

Wayfinder is a Personal Independence Operating System for the Neurodiverse.

Our goal is simple:

> Help people build independence, confidence, and life skills one successful day at a time.

Whether you are a developer, caregiver, educator, therapist, accessibility advocate, researcher, designer, or neurodiverse individual, your perspective is valuable.

Technology alone will not solve these challenges.

The best solutions come from people who live them every day.

---

# Our Guiding Principle

Every proposed contribution should be evaluated against one question:

> Does this help a neurodiverse person become more independent?

If the answer is yes, we want to hear about it.

---

# Ways to Contribute

You do not need to write code to contribute.

We welcome contributions in many forms.

## Share Ideas

Open an issue if you have:

- Feature ideas
- Improvement suggestions
- Real-world use cases
- Accessibility recommendations
- User experience feedback

---

## Improve Documentation

Documentation is one of the most important parts of this project.

You can help by:

- Fixing typos
- Improving clarity
- Writing tutorials
- Creating examples
- Explaining technical concepts

---

## Accessibility Reviews

Accessibility is a core requirement.

We welcome feedback regarding:

- Cognitive accessibility
- Executive function support
- Visual design
- Reading difficulty accommodations
- ADHD support
- Autism support
- User experience improvements

---

## Report Bugs

If you encounter a bug, please open an issue and include:

- What happened
- What you expected to happen
- Steps to reproduce
- Screenshots if relevant

---

## Contribute Code

Developers are welcome to contribute:

- Bug fixes
- New features
- Accessibility improvements
- Tests
- Documentation
- Performance improvements

Please discuss significant changes before investing substantial effort.

---

# Before You Create a Pull Request

Please ensure:

- The change aligns with the mission of Wayfinder.
- The change improves or supports user independence.
- Documentation has been updated if necessary.
- Existing functionality remains intact.
- Accessibility considerations have been reviewed.

---

# Design Principles

When contributing to Wayfinder, keep these principles in mind.

## Independence First

Wayfinder should help users do more for themselves.

The objective is not to replace people.

The objective is to increase capability and autonomy.

---

## Simplicity Over Complexity

The simplest solution that helps users achieve their goals is usually the best solution.

Avoid unnecessary complexity.

---

## Accessibility First

Accessibility is not a later enhancement.

Accessibility is a core requirement.

All new features should consider:

- Cognitive load
- Reading difficulty
- Visual clarity
- Predictability
- Ease of use

---

## Respect and Dignity

Wayfinder exists to empower.

Contributions should reinforce:

- Respect
- Dignity
- Inclusion
- Self-determination

Avoid language or features that portray individuals as problems to be managed.

Focus on strengths, capability, and support.

---

# Coding Standards

As the project evolves, coding standards and architectural guidance will be documented.

For now:

- Keep solutions simple
- Write readable code
- Prefer maintainability over cleverness
- Document important design decisions
- Add tests where practical

---

# Community Expectations

We are building a welcoming and inclusive community.

Please:

- Be respectful
- Assume positive intent
- Be open to feedback
- Be patient with newcomers
- Encourage collaboration
- Focus on solving problems together

Disagreements are inevitable.

Disrespect is not.

A formal Code of Conduct will be published as the project grows.

---

# Our Long-Term Vision

Wayfinder is intended to become an open-source platform that helps neurodiverse individuals build greater independence in everyday life.

Potential future capabilities include:

- Daily Readiness
- Reading Coach
- Writing Coach
- Math Coach
- Transportation Support
- Social Skills Support
- Executive Function Assistance
- Daily Living Skills

The possibilities are significant.

The mission remains simple:

> Build independence one successful day at a time.

Thank you for helping build Wayfinder.

We are glad you are here.
